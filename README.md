## Overview

This repository contains the source code for my personal website at [upayan.dev](https://upayan.dev). The project combines my portfolio with a background stats service.

The website displays my projects, verified certificates, and live status tiles. The background service streams my Spotify playback, Discord presence, and computer health metrics to the site.
